**Design choices that limit any pass (stated before the gate):** this is a **planted toy chemistry** (Vasas-2012-type cores written by hand, plus random side reactions), not a random RAF set from a polymer chemistry. The reading reaction exists by design; what selection decides is whether compartments carrying it spread. The gate searches for a world where a designed anticipator wins, so tuning the world until it can win is a design choice. The reading price is per unit of cue-read flux (extra decay of the reader), **not per nat**.

Grid: decay δ ∈ {0.1, 0.3} × mean phase length P ∈ {20, 60} × reading price c ∈ {0, 0.2}. Head-to-head: 100 anticipator (A2-core) vs 100 non-reader (A1-core) compartments, heredity on, cued world, T = 1000, pilot seeds 101–105. **Pass:** the anticipator lineage's frequency is ≥ 0.75 in ≥ 4/5. **Choice rule:** the largest c, then the smallest δ, then the smallest P. **If none passes:** report that a cue-reading core does not pay in this class, and run no test.

## Addendum (written after the gate output, before any test): a validity control
Every cell passed at 1.00, which is too clean. It could mean that A2 is a stronger core for reasons other than reading (for example, cross-feeding from synthesizing B1). Before any prereg, the same contest is re-run at the chosen world (δ 0.1, P 20, c 0.2) on the same pilot seeds in two control worlds: (a) **random cue** (same reading, no timing information) and (b) **reader off** (A2 = A1, so the contest is neutral). The gate counts as **valid** only if both controls give anticipator-lineage frequency ≥ 0.75 in ≤ 2/5 seeds. If the gate is invalid, the design is not run as is.
